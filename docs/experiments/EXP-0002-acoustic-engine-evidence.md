# EXP-0002: waves or rays for the acoustic engine

Status: complete, 2026-11-15. **Retrospective**: the measurements were made while the
decision was being formed, before this project had a pre-registration rule.

## Question

Which physical model can compute the echoes of echolocation training targets accurately
enough to train with, at a cost that allows interactive use?

## What was fixed before measuring, and what was not

- Fixed beforehand: the acceptance unit and level. Echo level in the 2 to 4 kHz click
  band must be within 1.0 dB of the reference, because about 1 dB is the smallest level
  difference listeners notice.
- Set after seeing results: the 1.5 dB tolerance on the size cue, the 8% and 5% limits
  on spectrum error, and the tolerances that pin the wave solver's own accuracy. These
  were chosen to hold the measured behaviour in place against regression. They are
  marked retrospective in `docs/quality/budgets.toml`.

## Method, results and reproduction

The method and every result are in `docs/acoustics/validation.md` and
`docs/decisions/0002-acoustic-engine.md`. All numbers are regenerated by the test suite
on every change:

```
uv run pytest tests/acoustics           # everyday checks
uv run pytest tests/acoustics -m slow   # fine grids
```

## Outcome

Geometric acoustics with edge diffraction for production; a wave solver as referee;
a known gap for objects about one wavelength around (decision 2).
